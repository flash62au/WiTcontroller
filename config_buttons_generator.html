Experimental WiTcontroller configuration generator

Select only the settings you want to override. The generated file is a personal config_buttons.h; save it beside WiTcontroller.ino and upload the sketch.

Refer to the readme or to config_button_example.h for details on the configuration options below.

This page runs entirely in your browser. It does not upload or store your configuration.

Not all configuration options are available in this tool.
For some advanced options (e.g. custom function searches, using a potentiometer, etc.) either edit the generated file, or revert back to the old process of copying config_buttons_example.h. Renaming the copy config_buttons.h, then editing that file as needed.

Warning! This tool is highly experimental, and has had only limited testing.
If you have any difficulties loading the config_buttons.h file generated by it, revert back to the old process of copying config_buttons_example.h. Renaming the copy config_buttons.h, then editing that file as needed.
