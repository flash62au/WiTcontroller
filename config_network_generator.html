Experimental WiTcontroller Network Configuration Generator

Enter your Wi-Fi networks and optional network settings. The generated config_network.h can be saved in the same folder as WiTcontroller.ino.

Select only the settings you want to override. The generated file is a personal config_network.h; save it in the same folder as WiTcontroller.ino and upload the sketch.

Refer to the readme or to config_network_example.h for details on the configuration options below.

This page runs entirely in your browser. It does not upload or store your configuration. It cannot retrieve previously created configurations.

Warning! This tool is highly experimental, and has had only limited testing.
If you have any difficulties loading the config_network.h file generated by it, revert back to the old process of copying config_network_example.h. Renaming the copy config_network.h, then editing that file as needed.

If you do encounter any problems I would be glad to hear about them to try to resolve them (akersp62@gmail.com)
